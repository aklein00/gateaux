# Templates

Copy, fill, paste into the right folder. Do not keep blank copies around.

---

## Weekly status → `PRESENT/status.md` (refresh the top)

```
Week of:
One-liner:
Health: green / yellow / red
Shipped:
Didn’t ship, and why:
Playtests:
Ask for next week:
```

---

## This week → `FUTURE/this-week.md`

```
Week of:
Done when: (one observable sentence)
In: (max 5)
Out:
Playtest plan:
Files likely to move:
```

---

## Decision → `PAST/decision-log.md`

```
## D-XXX — Title (YYYY-MM-DD)

Consequence.

```
