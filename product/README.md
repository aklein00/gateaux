# Gateaux — Product Office

This folder is the living tracker for Gateaux: what we already built, what the game actually is today, and what we will do next.

It is written as if a program manager and a creative manager share one desk. They do, even when that desk is one person.

Design intent still lives in `Gateaux/docs/` (GDD, characters, art). This folder is the operating system on top of that intent: status, decisions, voice, and the next slice of work.

---

## How to use this folder

| If you need… | Open |
|---|---|
| What the game is, and whether it is working | `PRESENT/status.md` |
| Coins, diamonds, XP, pastry payouts | `PRESENT/economy.md` |
| What to build this week | `FUTURE/this-week.md` |
| Now / Next / Later | `FUTURE/roadmap.md` |
| Ranked work with rationale | `FUTURE/backlog.md` |
| Why we chose something | `PAST/decision-log.md` |
| What shipped | `PAST/changelog.md` |
| How it should *feel* and sound | `CREATIVE/player-feel.md` and `CREATIVE/voice-and-tone.md` |
| Solo cadence (rituals, templates) | `OPS/how-we-work.md` |

**Rule:** update Present and Future when you ship. Do not wait for a “real” PM to exist.

## Why this folder exists (jobs)

This is also a portfolio artifact for program / creative manager roles. A hiring manager should be able to skim it in ten minutes and see:

- Honest status, not a pitch deck
- A creative north star that can be used to say no
- A roadmap that sequences *feel* before *features*
- Decision hygiene (what we chose, what we deferred, why)
- A solo operating cadence that would still work on a small team

If you are reading this in an interview packet: start with [`PRESENT/status.md`](PRESENT/status.md), then [`CREATIVE/player-feel.md`](CREATIVE/player-feel.md), then [`FUTURE/roadmap.md`](FUTURE/roadmap.md).
