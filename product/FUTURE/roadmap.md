# Roadmap

Horizon, not a Gantt chart. If a line does not make the lesson lighter or funnier, it does not belong in Now.

## Now — Feel slice (shipped 14 Aug 2026)

First five minutes are a Duolingo-café snack. Stranger playtest is the remaining exit.

- One tap from Start into a language pick, then a Marcel question.
- Session one is Marcel: casual hellos.
- UI copy talks like the staff.
- Timer off by default.
- Correct answers get a cat line.
- Tutorial is one spoken beat plus language choice.

Exit still open: a stranger finishes one lesson without asking “what am I supposed to do?”

## Next — Two verbs, one café

Listen-first and native-first customers shipped with the feel slice. Remaining:

- Hearts-or-cakes as a gentle fail state instead of a ticking ring (timer still available as Rush Hour).
- Tap-to-commit so CHECK is gone entirely.
- Recorded VO instead of TTS.

Exit: hub and lesson feel like the same joke, confirmed by playtest.

## Later — World, not systems

Only after Next.

- **Local slang Option B (chosen, parked 17 Aug 2026):** country default + a few FR/ES city packs (~8 packs × 10 café lines). Mexico / France / Québec / Spain (+ Argentina if we want one more). Cities: Mexico City, Cancún, Paris, Montréal, Barcelona or Madrid, Buenos Aires. Generate offline with a cheap model, human-edit, serve static JSON. No flag UI — a Marcel “heading to Cancún?” chip after the first cake. Not a 50-destination world atlas (that is another game).
- Québec / Mexico flavor as *lines* is the first slice of Option B, not a separate flag picker.
- Bisou and Gaston as optional “mood” lessons, still short.
- Recorded VO for the five cats (even 20 lines each would change everything).
- Café dress-up as a *reward* for streaks, not a sim.
- Shareable web link (`gateaux.utilityinfielder.com`).
- A third language, if two feel great.
- More simple drills after Marcel/Amélie tap-to-match (Café / Bisou / Gaston still use quiz for now).
- Multiple-choice may eventually live only on the Cafe Counter, not in early lessons.

## Not on the roadmap

- Voice recognition.
- Grammar trees.
- Daily cake caps and premium “faster baking.”
- Italian / German / Japanese as a content strategy.
- AI as the teacher of record.
- Clash-style extra currencies.

Those are other games. Ours is: small talk, cakes, cats.
