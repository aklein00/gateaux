# Gateaux - Language Learning Café Game

A charming language learning game where you run a café and learn languages by serving customers from around the world.

## 🎮 How to Play

1. **Open the Game**: Open `index.html` in your web browser
2. **Choose a Language**: Click on Spanish 🇪🇸 or French 🇫🇷 to start learning
3. **Learn Recipes**: Complete language "recipes" through fun minigames
4. **Serve Customers**: Practice your skills by serving customers in your café
5. **Build Your Phrasebook**: Keep track of all the phrases you've learned

## 🌟 Features

- **Interactive Learning**: Three types of minigames (matching, listening, fill-in-the-blank)
- **Café Management**: Serve customers and earn tips
- **Progress Tracking**: Your learning progress is automatically saved
- **Beautiful Design**: Warm, café-inspired interface
- **Two Languages**: Spanish and French with more coming soon

## 🎯 Game Modes

### Recipe Learning
- Choose from different language "recipes" (Greetings, Café Basics, Navigation)
- Learn 3-5 phrases per recipe through interactive minigames
- Progress through difficulty levels

### Café Service
- Serve customers who speak different languages
- Practice your learned phrases in real scenarios
- Earn tips to customize your café

### Phrasebook
- Review all learned phrases
- Quick access to translations
- Coffee Rush mode for rapid practice

## 🛠️ Technical Details

- **Built with**: HTML5, CSS3, JavaScript (ES6 modules)
- **No Dependencies**: Pure vanilla JavaScript
- **Responsive Design**: Works on desktop and mobile
- **Local Storage**: Progress automatically saved in browser

## 🎨 Customization

The game is designed to be easily customizable:
- Add new languages by editing `languageData.js`
- Modify the café appearance in the CSS files
- Add new minigame types in `minigames.js`
